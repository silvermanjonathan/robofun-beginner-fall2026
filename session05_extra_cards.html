Card A · build it from the steps · about 15 minutes

Letter grades

You write a function called grade_of that takes a score and returns a grade. Then you use it on a whole list of scores.

The rule: 90 or more returns "A". 80 or more returns "B". 70 or more returns "C". Anything lower returns "not yet".

Make a new file called Jonathan_session05_grades.py, with your own first name in place of Jonathan.

  1. At the top of the file, write def grade_of(score):. In its body, use flat gates with a return in each one, the same shape as fare(age) on the session 5 page.
  2. Under the function, at the left edge, test it with three lines: print(grade_of(95)), print(grade_of(80)), and print(grade_of(42)).
  3. Make the list scores = [72, 95, 88, 97, 67].
  4. Loop through scores. On each pass, call grade_of, store the return value in a variable called grade, and print a line like 72 gets C with an f-string.

Before you run: 95 is 90 or more, and it is also 80 or more. Why does grade_of(95) return "A" and not "B"?

return ends the function. 95 passes the first gate, the function returns "A", and the gate for 80 never runs.

Go further

Write a second function, count_grade(scores, letter). It returns how many scores in the list get that grade. It has a counter and a loop, and it calls grade_of inside its gate. Put its def under grade_of and above the lines that print. With the list above, count_grade(scores, "A") returns 2 and count_grade(scores, "B") returns 1.

Card B · build it from the steps · about 20 minutes

Dice game

You and the computer each roll two dice for five rounds. The higher total wins the round. You build the game from three small functions.

Make a new file called Jonathan_session05_dice.py, with your own first name in place of Jonathan.

The first function is done for you. It returns one random number from 1 to 6. Type it in:

import random

def roll():
    return random.choice([1, 2, 3, 4, 5, 6])
  1. Write roll_two(). It returns the total of two rolls. It calls roll twice and adds the two return values.
  2. Write winner_of(you, computer). It returns "you" when the first number is higher, "computer" when the second number is higher, and "tie" when they are equal. Use flat gates and three returns.
  3. Under the three functions, at the left edge, make a counter your_wins = 0.
  4. Write a for loop with range(1, 6). Inside it: the line input("Press Enter to roll."), then one call to roll_two for you, one call to roll_two for the computer, and one call to winner_of. Store all three return values.
  5. Still inside the loop, print the round with an f-string. Then add 1 to your_wins when the winner is "you".
  6. After the loop, print how many rounds you won.

The dice are random, so your numbers will be different from this finished run.

Before you run: What is the lowest number roll_two() can return, and what is the highest?

The lowest is 2, from two rolls of 1. The highest is 12, from two rolls of 6.

Go further

Write roll_many(count). It returns the total of count rolls. Use an accumulator and a for loop with range(count). Then print roll_many(10) a few times.

Question: Every value roll_many(10) returns is between 10 and 60. Why?

Ten rolls of 1 add up to 10, and ten rolls of 6 add up to 60. Every other set of ten rolls is in between.

Card C · bug hunt · about 15 minutes

Bug hunt: the average

This program has 3 bugs. The four numbers add up to 80, and 80 divided by 4 is 20, so it is supposed to print this:

A finished run

20.0

Make a new file called Jonathan_session05_bugs.py, with your own first name in place of Jonathan.

Type the program exactly as it is here, bugs and all:

print(average_of([12, 20, 28, 20]))

def total_of(numbers):
    total = 0
    for n in numbers:
        total = total + n
        return total

def average_of(numbers):
    print(total_of(numbers) / len(numbers))

One bug stops the program with an error. The other two give no error: the program runs and prints the wrong thing.

Fix one thing per run. For each bug, write down the line number and what you changed.

Clues, if you are stuck. Open one at a time. The next clue is inside the one before it.

Bug 1: the error says average_of is not defined, and yet the def is in the file. Python reads a file from the top. Which does it reach first, the def or the call?

Bug 2: the output has the word None in it. Which function prints a value when it should return the value?

Bug 3: the output is 3.0, and 12 divided by 4 is 3. Why did total_of return only the first number? Look at how far the line return total is indented.
