Chunk 9 of 9

A letter instead of a number

This is the finished game. The show and winner functions are above it in your file. The players type 5, X, 5, 1, 4, 2, and 6.

board = ["1", "2", "3", "4", "5", "6", "7", "8", "9"]
marks = ["X", "O"]
turns = 0
while turns < 9 and winner(board) == "":
    show(board)
    player = marks[turns % 2]
    move = input(f"Player {player}, pick a square: ")
    if move == "X" or move == "O":
        print("Type the number of a square, not a mark.")
    elif move in board:
        spot = int(move) - 1
        board[spot] = player
        turns = turns + 1
    else:
        print("That is not a free square. Try again.")

show(board)
if winner(board) == "":
    print("Nobody wins. It is a draw.")
else:
    print(f"{winner(board)} wins!")

Each row is one pass of the while loop. move is what was typed on that pass. Write the value of player, which marks[turns % 2] gives. The gate that starts if move == "X" or move == "O": has three branches. Write which branch runs: if, elif, or else.
