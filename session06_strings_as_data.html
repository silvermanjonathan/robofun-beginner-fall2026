Chunk 1 of 8

A string is a row of slots

Text is indexed exactly like a list. Slot 0 is the first character. len counts the characters, spaces included.

word = "SPYGLASS"
print(word[0])
print(word[7])
print(len(word))

Predict: Eight letters. What is in slot 7?

The last S. Same rule as lists: the last slot is one less than the length.

What actually happens

S
S
8

Chunk 2 of 8

Slicing takes a run of slots

Two numbers in the brackets with a colon between them take everything from the first up to, but not including, the second. Leave a side blank and Python uses the end.

word = "SPYGLASS"
print(word[0:3])
print(word[3:])
print(word[:3])
print(word[2:5])

Predict: word[0:3] gives three letters or four?

Three: slots 0, 1, 2. The same stop-before rule as range. You have now met it three times, which is why it is on the ledger card.

What actually happens

SPY
GLASS
SPY
YGL

Chunk 3 of 8

Cleaning text you did not type

Input from a person is messy. strip removes spaces from both ends. upper and lower change the case. None of them change the original; each one hands back a new string, which is why the result has to be stored.

raw = "   ada lovelace   "
clean = raw.strip()
print(len(raw), len(clean))
print(clean.upper())
print(raw.upper())
print(len(raw))

Predict: After raw.strip(), how long is raw?

Still 18. strip handed back a shorter string and left the original alone. Forgetting to store the result is the same mistake as calling int(age) without assigning it, back in session 1.

What actually happens

18 12
ADA LOVELACE
   ADA LOVELACE   
18

Chunk 4 of 8

in asks whether something is inside

The word in hands back True or False. It works on strings and on lists, and it saves you the loop you would otherwise write to go looking.

word = "SPYGLASS"
print("GLA" in word)
print("Z" in word)
print("S" in word)
riders = ["Ada", "Grace"]
print("Ada" in riders)

Predict: Does in look for a single letter only, or a whole run of letters?

A whole run, in order, with nothing between. GLA is in SPYGLASS; GAL is not. On a list it looks for one whole item, not part of one.

What actually happens

True
False
True
True

Chunk 5 of 8

replace swaps every copy

replace hands back a new string with every occurrence swapped. Every one, not just the first. Store the result.

message = "MEET AT NOON"
no_spaces = message.replace(" ", "*")
print(no_spaces)
print(message.replace("O", "0"))
print(message)

Predict: NOON has two Os. How many get replaced?

Both. And the original is unchanged on the last line, because replace hands back a copy.

What actually happens

MEET*AT*NOON
MEET AT N00N
MEET AT NOON

Chunk 6 of 8

Building a string one character at a time

Start with an empty string, then add to it inside a loop. This is the accumulator from session 3 with text instead of numbers. Putting the new character in front instead of behind reverses the message.

word = "SPYGLASS"
forward = ""
backward = ""
for ch in word:
    forward = forward + ch
    backward = ch + backward
print(forward)
print(backward)

Predict: Two accumulators, one loop. Which line reverses the word, and why?

The one that puts ch first. Each new character shoves the growing string to the right, so the last character read ends up at the front.

What actually happens

SPYGLASS
SSALGYPS

Chunk 7 of 8

A pair-swap cipher

Swap every pair of characters. Spaces get turned into stars first so the word breaks do not give the message away, and an odd-length message gets one star added so the last pair is complete. The step of 2 in range hands out 0, 2, 4 and skips the odd slots, because each pass handles two characters.

message = "MEET AT NOON"
message = message.replace(" ", "*")
if len(message) % 2 == 1:
    message = message + "*"

out = ""
for i in range(0, len(message), 2):
    out = out + message[i + 1] + message[i]
print(out)

Predict: Twelve characters, six pairs. What does the first pair, ME, become?

EM. Each pair comes out in the other order. The padding gate matters: without it, message[i + 1] reaches past the end on the last pass and you get an IndexError.

What actually happens

EMTEA**TONNO

Chunk 8 of 8

The same code decodes it

Swapping a pair twice puts it back. Feed the output of the encoder into the encoder again and the original returns. Ciphers that behave this way need only one piece of code.

def pair_swap(text):
    text = text.replace(" ", "*")
    if len(text) % 2 == 1:
        text = text + "*"
    out = ""
    for i in range(0, len(text), 2):
        out = out + text[i + 1] + text[i]
    return out

secret = pair_swap("MEET AT NOON")
print(secret)
print(pair_swap(secret))
print(pair_swap(secret).replace("*", " "))

Predict: Run it twice on the same message. Do you get the message back exactly?

Yes, with stars where the spaces were. Turning the stars back into spaces is one more replace. Note that the function returns rather than prints, which is what lets the second call take the first one's output.

What actually happens

EMTEA**TONNO
MEET*AT*NOON
MEET AT NOON

Hinge question · reaches back two weeks

Before you build

Question: From session 4: the encoder is a function that returns. Explain in one sentence why pair_swap(pair_swap("HELLO")) works, and what it would do if pair_swap ended in print instead of return.

The inner call becomes a string, and the outer call takes that string as its argument. With print the inner call would hand back None, and the outer call would crash trying to call replace on None.

Build · 25 minutes

Build: a message cleaner and a cipher

  1. Write clean(text) that strips the ends, raises the case, and returns the result.
  2. Write pair_swap(text) from the chunk above, without looking at it if you can.
  3. Ask for a message, clean it, encode it, and print the secret.
  4. Decode your own secret by calling the encoder a second time.
  5. Test it on a message with an odd number of characters and confirm the padding gate fires.
