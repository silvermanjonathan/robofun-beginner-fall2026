Times table

You make a program that asks which times table the player wants, then prints that table from 1 to 12.

  1. Ask which times table. Store the answer in a variable called n and change its type to a number.
  2. Write a for loop with range(1, 13). Call the loop variable i.
  3. Inside the loop, make a variable called answer. Its value is n times i.
  4. Still inside the loop, print one line of the table with an f-string. The x in the output is the letter x, typed inside the f-string.

Before you run: The table stops at 12. Why does the range say 13?

range(1, 13) starts at 1 and stops before 13, so the last value of i is 12.

Part 2. Count how many of the twelve answers are over 50. Use a counter with a gate. For the 7 times table it should print 5 of the answers are over 50.

Card B · finish the starter · about 20 minutes

Coin flips

The computer flips a coin twenty times with random.choice and prints each flip. You get a starter that runs but only counts one side.

Make a new file called Jonathan_session03_coins.py, with your own first name in place of Jonathan.

Type the starter:

import random

sides = ["heads", "tails"]
heads = 0

for flip in range(1, 21):
    result = random.choice(sides)
    print(f"Flip {flip}: {result}")
    if result == "heads":
        heads = heads + 1

print(f"Heads: {heads}")

The gate is inside the for loop, so the if line is indented 4 spaces and its block is indented 8 spaces. The gate runs once on every flip.

Before you run: Look at the gate. On a flip that lands tails, which lines inside the loop run?

The result line and the print line. The gate's condition is False for tails, so its block is skipped and nothing counts that flip.

The flips are random, so your run will be different from this one.

The start and end of one run of the starter

Flip 1: heads
Flip 2: tails
Flip 3: heads
...
Flip 20: heads
Heads: 12

The starter counts heads and nothing else. The tails count is missing, and so is the result.

  1. Make a second counter, tails = 0, under heads = 0.
  2. Add an else to the gate, lined up with the if. In its block, add 1 to tails.
  3. After the loop, print the tails count the same way the heads count is printed.
  4. Under that, add a three-way gate on the two counters. More heads prints Heads wins. Equal prints A draw. Anything else prints Tails wins.

The last three lines of a finished run

Heads: 12
Tails: 8
Heads wins.

Check: run it three times. Heads plus tails is 20 every time.

Go further

Find the longest run of heads: the most times in a row the coin landed heads. You need two more counters above the loop, run = 0 and longest = 0. Inside the heads block, add 1 to run. Inside the else block, set run back to 0, because a tails flip ends the run. Then, after the gate and still inside the loop, use best so far: if run is greater than longest, store run in longest. Print longest after the loop. For the run that printed the lines above, it is 4. Your run will give its own number.

Card C · bug hunt · about 15 minutes

Bug hunt: the score report

This program has 3 bugs. It is supposed to print this:

A finished run

over 80: 3
best: 97
last score: 67

Make a new file called Jonathan_session03_bugs.py, with your own first name in place of Jonathan.

Type the program exactly as it is here, bugs and all:

scores = [72, 95, 88, 97, 67]
best = 100
for s in scores:
    count = 0
    if s > 80:
        count = count + 1
    if s > best:
        best = s
print(f"over 80: {count}")
print(f"best: {best}")
print(f"last score: {scores[5]}")

One bug stops the program with an error. The other two give no error: the program runs and prints wrong numbers. You find those two by comparing your output with the finished run above.

Fix one thing per run. For each bug, write down the line number and what you changed.

Clues, if you are stuck. Open one at a time. The next clue is inside the one before it.

Bug 1: the error names line 11. The list has 5 items. What is the index of the last item?

Bug 2: over 80 prints 0. Look at where count = 0 is. How many times does that line run?

Bug 3: best prints 100, and no score in the list is 100. What starting value is lower than every score?

Go further

Add a variable called lowest and find the lowest score with best so far. Print it. Then check it against min(scores). Both should give 67.
