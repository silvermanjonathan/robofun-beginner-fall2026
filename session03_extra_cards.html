Times table

You make a program that asks which times table the player wants, then prints that table from 1 to 12.

  1. Ask which times table. Store the answer in a variable called n and change its type to a number.
  2. Write a for loop with range(1, 13). Call the loop variable i.
  3. Inside the loop, make a variable called answer. Its value is n times i.
  4. Still inside the loop, print one line of the table with an f-string. The x in the output is the letter x, typed inside the f-string.

Before you run: The table stops at 12. Why does the range say 13?

range(1, 13) starts at 1 and stops before 13, so the last value of i is 12.

Go further

Part 1. Add up the twelve answers with an accumulator. After the loop, print the total. For the 7 times table it should print The twelve answers add up to 546.

Part 2. Count how many of the twelve answers are over 50. Use a counter with a gate. For the 7 times table it should print 5 of the answers are over 50.

Card B · finish the starter · about 20 minutes

Rock paper scissors

The player plays five rounds against the computer. The computer picks its move with random.choice. You get a starter that runs but gets the result of some rounds wrong.

The rules: rock beats scissors, paper beats rock, scissors beats paper. The same move from both players is a tie.

Make a new file called Jonathan_session03_rps.py, with your own first name in place of Jonathan.

Type the starter:

import random

moves = ["rock", "paper", "scissors"]
your_wins = 0

for round_number in range(1, 6):
    print(f"Round {round_number}")
    you = input("rock, paper, or scissors: ")
    computer = random.choice(moves)
    print(f"The computer picked {computer}.")

    if you == computer:
        print("Tie.")
    elif you == "rock" and computer == "scissors":
        print("You win the round.")
        your_wins = your_wins + 1
    else:
        print("The computer wins the round.")

print(f"Rounds you won: {your_wins}")

Here are the first two rounds of one run of the starter. The computer picks at random, so your rounds will be different.

Two rounds of the starter

Round 1
rock, paper, or scissors: rock
The computer picked rock.
Tie.
Round 2
rock, paper, or scissors: paper
The computer picked rock.
The computer wins the round.

Round 2 is wrong. Paper beats rock, so the player won that round. The gate has one way for the player to win, and the rules have three.

Before you change anything: Read the gate. Which two ways for the player to win are missing?

Paper against rock, and scissors against paper.

  1. Add two more elif lines with their blocks, one for each missing way to win. Put them above the else.
  2. Make a counter called computer_wins. Start it at 0 above the loop. Add 1 to it in the else block.
  3. Change the last line so it prints both scores, like this: You won 2. The computer won 2.
  4. Under that line, add a three-way gate that compares the two scores and prints You win the match. or The match is a tie. or The computer wins the match.

The end of a finished run

Round 5
rock, paper, or scissors: paper
The computer picked rock.
You win the round.
You won 2. The computer won 2.
The match is a tie.

Check: play until you have seen paper against rock and scissors against paper. Both should print You win the round.

Go further

Type rokc as your move. The program counts it as a win for the computer. Fix that with a while loop that asks again until the move is rock, paper, or scissors. The loop goes inside the for loop, where the input line is now. Set you = "" just above it, so the loop has a value to test on its first check.

Card C · bug hunt · about 15 minutes

Bug hunt: the score report

This program has 3 bugs. It is supposed to print this:

A finished run

over 80: 3
best: 97
last score: 67

Make a new file called Jonathan_session03_bugs.py, with your own first name in place of Jonathan.

Type the program exactly as it is here, bugs and all:

scores = [72, 95, 88, 97, 67]
best = 100
for s in scores:
    count = 0
    if s > 80:
        count = count + 1
    if s > best:
        best = s
print(f"over 80: {count}")
print(f"best: {best}")
print(f"last score: {scores[5]}")

One bug stops the program with an error. The other two give no error: the program runs and prints wrong numbers. You find those two by comparing your output with the finished run above.

Fix one thing per run. For each bug, write down the line number and what you changed.

Clues, if you are stuck. Open one at a time.

Bug 1: the error names line 11. The list has 5 items. What is the index of the last item?

Bug 2: over 80 prints 0. Look at where count = 0 is. How many times does that line run?

Bug 3: best prints 100, and no score in the list is 100. What starting value is lower than every score?

Go further

Add a variable called lowest and find the lowest score with best so far. Print it. Then check it against min(scores). Both should give 67.
