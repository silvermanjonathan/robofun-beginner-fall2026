How the cards work

  • Pick any one card. The three cards do not depend on each other.
  • Each card needs a new file. The card gives the file name.
  • Say what you think the program will do before you run it.
  • Change one thing, then run it. One change per run.

Card A · build it from the steps · about 15 minutes

Silly story

You make a program that asks four questions, then prints a three-line story that uses the answers.

Make a new file called Jonathan_session01_story.py, with your own first name in place of Jonathan.

A finished run

Name an animal: penguin
Name a food: tacos
Name a place: the library
Pick a whole number: 7
One day the penguin walked into the library.
It ordered 7 plates of tacos.
Then it changed its mind and ordered 14.
  1. Ask the four questions with input. Store each answer in its own variable.
  2. The number comes back as text. Change its type with int(), on a line of its own.
  3. Make a new variable called double. Its value is the number times 2. The times sign in Python is *.
  4. Print the three story lines. Each one is an f-string.

Try it: Take out the int() line and run the program again with 7. What does the last line print now? Put the line back afterwards.

Then it changed its mind and ordered 77. Without int(), number is the text 7. Text times 2 is the same text written twice.

Go further

Add a fifth question and a fourth story line that uses its answer. Then change the story to one of your own.

Card B · build it from the steps · about 15 minutes

Age calculator

You make a program that asks for a name and an age, then prints how old that person is in days and in hours.

Make a new file called Jonathan_session01_age.py, with your own first name in place of Jonathan.

A finished run

Your name: Ada
Your age in years: 11
Ada, you are about 4015 days old.
That is about 96360 hours.
In 10 years you will be 21.
  1. Ask for the name and the age. Change the type of the age to a number.
  2. Make a variable called days. Its value is the age times 365.
  3. Make a variable called hours. Its value is days times 24.
  4. Make a variable called later. Its value is the age plus 10.
  5. Print the three sentences. Each one is an f-string.

Before you run: Suppose the line that makes hours came before the line that makes days. What would Python do?

It stops with NameError: name 'days' is not defined Python runs the lines from the top. On the hours line, days has no value yet.

Check: run it with Ada and 11. Your three lines should match the finished run above.

Go further

Add minutes and seconds, each with its own printed sentence. An hour has 60 minutes and a minute has 60 seconds. For age 11 the program should print 5781600 minutes and 346896000 seconds.

Card C · bug hunt · about 15 minutes

Bug hunt: the snack machine

This program has 3 bugs. When you type pretzels and 3, it is supposed to print this:

A finished run

Which snack? pretzels
How many bags? 3
You get 4 bags of pretzels. One is free.

Make a new file called Jonathan_session01_bugs.py, with your own first name in place of Jonathan.

Type the program exactly as it is here, bugs and all:

snack = input("Which snack? ")
count = input("How many bags? ")
extra = count + 1
print("You get {extra} bags of {snak}. One is free.")
  1. Run it.
  2. If there is an error, read its last line first.
  3. Fix one thing. Run it again.
  4. Keep going until the output matches the finished run above.

For each bug, write down the line number and what you changed.

Clues, if you are stuck. Open one at a time.

Bug 1: the error names line 3. What type is the value of count?

Bug 2: the program runs, but it prints the curly braces. Which letter is missing in front of the opening quote mark?

Bug 3: the error says a name is not defined. Compare how that name is spelled with the name on line 1.
