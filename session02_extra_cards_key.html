Card B · finish the starter · about 15 minutes

Guess my number

Before you run: the stopping condition is guess != secret. The loop stops when the guess is 37.

This is the program with both Go further parts.

secret = 37
guess = 0
tries = 0

while guess != secret:
    guess = input("Guess my number, 1 to 50: ")
    guess = int(guess)
    tries = tries + 1
    if guess < secret:
        print("Too low.")
    elif guess > secret:
        print("Too high.")

print(f"You got it in {tries} tries.")
if tries <= 4:
    print("Sharp guessing.")
elif tries <= 7:
    print("Not bad.")
else:
    print("That took a while.")
