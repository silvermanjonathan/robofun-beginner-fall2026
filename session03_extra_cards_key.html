Times table

Before you run: range stops before its second number, so range(1, 13) gives 1 to 12.

This is the program with both Go further parts.

n = input("Which times table? ")
n = int(n)

total = 0
over_50 = 0
for i in range(1, 13):
    answer = n * i
    print(f"{n} x {i} = {answer}")
    total = total + answer
    if answer > 50:
        over_50 = over_50 + 1

print(f"The twelve answers add up to {total}.")
print(f"{over_50} of the answers are over 50.")

Card B · finish the starter · about 20 minutes

Rock paper scissors

Before you change anything: the two missing ways to win are paper against rock, and scissors against paper.

import random

moves = ["rock", "paper", "scissors"]
your_wins = 0
computer_wins = 0

for round_number in range(1, 6):
    print(f"Round {round_number}")
    you = input("rock, paper, or scissors: ")
    computer = random.choice(moves)
    print(f"The computer picked {computer}.")

    if you == computer:
        print("Tie.")
    elif you == "rock" and computer == "scissors":
        print("You win the round.")
        your_wins = your_wins + 1
    elif you == "paper" and computer == "rock":
        print("You win the round.")
        your_wins = your_wins + 1
    elif you == "scissors" and computer == "paper":
        print("You win the round.")
        your_wins = your_wins + 1
    else:
        print("The computer wins the round.")
        computer_wins = computer_wins + 1

print(f"You won {your_wins}. The computer won {computer_wins}.")
if your_wins > computer_wins:
    print("You win the match.")
elif your_wins == computer_wins:
    print("The match is a tie.")
else:
    print("The computer wins the match.")
