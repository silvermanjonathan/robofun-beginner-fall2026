Three-question quiz

You make a quiz that asks three questions, keeps score, and prints a different last line for 3 right, 2 right, and anything lower.

Make a new file called Jonathan_session02_quiz.py, with your own first name in place of Jonathan.

Question 1 is done for you. Type it in.

score = 0

answer = input("How many legs does a spider have? ")
if answer == "8":
    print("Correct.")
    score = score + 1
else:
    print("No. A spider has 8 legs.")

The 8 is in quote marks because input gives text, and this gate compares text with text. No int() is needed here.

  1. Under question 1, write two more questions of your own. Each one has an input line and a gate, the same as question 1.
  2. After the third question, write a three-way gate on score. If score is 3, print Perfect. 3 out of 3. If score is 2, print Close. 2 out of 3. For anything else, print the score in an f-string.

Before you run: score = 0 is on line 1, above all three questions. Suppose you added a second score = 0 just above the last gate. A player gets all three right. What would the last line print?

You got 0 out of 3. Run it again. The second score = 0 replaces the count just before the gate reads it.

Check: run it three times. Get all three right, then two right, then none right. You should see three different last lines.

Card B · finish the starter · about 15 minutes

Guess my number

The program holds a secret number. The player keeps guessing until the guess is right. You get a starter that works but leaves one thing out.

Make a new file called Jonathan_session02_guess.py, with your own first name in place of Jonathan.

Type the starter:

secret = 37
guess = 0

while guess != secret:
    guess = input("Guess my number, 1 to 50: ")
    guess = int(guess)
    if guess < secret:
        print("Too low.")

print("You got it.")

The gate is inside the while loop, so the if line is indented 4 spaces and its block is indented 8 spaces. The gate runs once on every pass of the loop.

Before you run: Find the stopping condition. Which guess makes the loop stop?

The condition is guess != secret. The loop stops when the guess is 37, because then guess != secret is False.

Run the starter and guess 20, then 40, then 37.

What the starter prints

Guess my number, 1 to 50: 20
Too low.
Guess my number, 1 to 50: 40
Guess my number, 1 to 50: 37
You got it.

After the guess of 40 the program prints nothing, so the player gets no help.

  1. Add an elif under the if, lined up with it. When the guess is greater than the secret, print Too high.
  2. Run it again with 20, 40, 35, 37. It should print the finished run below.

Guess my number, 1 to 50: 40

Go further

Part 1. Count the guesses. Make a variable tries = 0 above the loop. Add 1 to it inside the loop. Change the last line to an f-string, so that the same four guesses print You got it in 4 tries.

Part 2. After that line, add a three-way gate on tries. For 4 or fewer print Sharp guessing. For 7 or fewer print Not bad. For anything else print That took a while.

Card C · bug hunt · about 15 minutes

Bug hunt: the door

A sign on a door says: you can come in if you are 13 or older and you have a ticket. This program is supposed to follow the sign. It has 3 bugs.

Make a new file called Jonathan_session02_bugs.py, with your own first name in place of Jonathan.

Type the program exactly as it is here, bugs and all:

age = input("Age: ")
ticket = input("Ticket? yes or no: ")
if age > 13 and ticket = "yes":
    print("Come in.")
else:
    print("Not today.")

Two of the bugs stop the program with an error. The third bug gives no error: the program runs and prints the wrong line for one of the four people in this table. Fix the first two bugs, one per run. Then run the program once for each row to find the third.

For each bug, write down the line number and what you changed.

Clues, if you are stuck. Open one at a time.

Bug 1: the error points at line 3. One equals sign stores a value. Two equals signs make a comparison.

Bug 2: the error says '>' not supported between instances of 'str' and 'int'. Which variable is still text?

Bug 3: test the row with 13 and yes. The sign says 13 or older. Which comparison means 13 or more?
