On an empty board all nine items are numbers, so whatever random.choice gives back is a free square, and the while condition is False the first time it is checked. When the computer first plays, one square holds your X, so one item in nine is a mark. Later in the game most of the items are marks, and the loop may run several times before a number comes up. Building it

  1. Add import random at the top of the file and change the game part to the lines on the card.
  2. Play three games. The computer plays badly, because it picks at random. Write down how many of the three you won.
  3. Put a probe inside the computer's while loop: print(f"tried {move}") as the first line of its block. Play again and count the tries on the computer's last turn.
  4. Let the computer go first: make it play X and you play O. One comparison on the if player == line changes, and so does the text of the question.
