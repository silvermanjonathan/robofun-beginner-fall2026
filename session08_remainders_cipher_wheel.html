Chunk 1 of 8

The remainder operator

The percent sign gives what is left over after division. It never gives more than one less than the number you divided by, which is exactly the behaviour a clock has.

print(14 % 12)
print(26 % 26)
print(29 % 26)
print(3 % 26)

Predict: Four answers. Which one is 0, and which one is unchanged by the operation?

What it actually prints

2
0
3
3

26 % 26 is 0, and 3 % 26 is still 3. Anything smaller than the divisor comes through untouched. Anything equal to it lands on zero and starts again.

Chunk 2 of 8

Clock arithmetic

Nine hours after 8 o'clock is 5 o'clock, not 17. The clock has 12 slots, so the count wraps. The remainder operator is that wrap, written down.

start = 8
for add in range(1, 13):
    print(start, "+", add, "=", (start + add) % 12)

Predict: Where in the list does the answer drop back to a small number?

What it actually prints

8 + 1 = 9
8 + 2 = 10
8 + 3 = 11
8 + 4 = 0
8 + 5 = 1
8 + 6 = 2
8 + 7 = 3
8 + 8 = 4
8 + 9 = 5
8 + 10 = 6
8 + 11 = 7
8 + 12 = 8

After 11 o'clock. Note the 0 where you would expect 12: a 12-slot clock numbered from zero has no 12 on it.

Chunk 3 of 8

A 26-slot rack

Line up the alphabet in a string. Now every letter has a slot number, and moving along the alphabet becomes adding to a number.

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
print(len(rack))
print(rack[0])
print(rack[25])
print(rack[12])

Predict: Twenty-six letters. What is A's slot number, and what is M's?

What it actually prints

26
A
Z
M

A is 0 and M is 12. The rack starts at zero, like every list and every string in this course.

Chunk 4 of 8

Find a letter's slot with a loop

To go from a letter to its number, walk the rack and stop when you see a match. This is the loop scan, and write it by hand once so you can see how many passes a search takes.

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
letter = "M"
slot = 0
found = 0
for i in range(26):
    if rack[i] == letter:
        slot = i
        found = 1
print("slot:", slot, "found:", found)

Predict: The loop keeps going after it finds M. Does that change the answer?

What it actually prints

slot: 12 found: 1

No, because nothing later matches. It does waste thirteen passes, and with break off the table this term that waste is the cost of the pattern.

Chunk 5 of 8

Shift with a wrap

Add the key to the slot number, wrap with the remainder, and look up the new slot. The wrap is what keeps Z from falling off the end.

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
key = 3
for letter in ["A", "M", "X", "Z"]:
    slot = rack.find(letter)
    print(letter, "->", rack[(slot + key) % 26])

Predict: X is at slot 23. Adding 3 gives 26. What letter comes out?

What it actually prints

A -> D
M -> P
X -> A
Z -> C

A. Slot 26 does not exist, and the remainder sends it round to 0. Without the wrap this line raises an IndexError on X, Y, and Z.

Chunk 6 of 8

The reveal: find does the scan for you

The previous chunk quietly used find. It walks the string looking for a match and gives the index, which is your loop scan in one call. It gives negative one when there is no match, and that is the case you have to handle yourself.

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
print(rack.find("A"))
print(rack.find("M"))
print(rack.find("Z"))
print(rack.find("!"))
print(rack.find(" "))

Predict: What does find give for a character that is not in the rack?

What it actually prints

0
12
25
-1
-1

Negative one. That is not an index. It is the sign that nothing matched, and you must gate on it before you use the result. Your loop-scan version used a found flag for the same reason.

Chunk 7 of 8

Encode a whole message

Walk the message, shift the letters, and pass anything else through untouched. The gate on the negative result from find is what protects the spaces.

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def shift(text, key):
    out = ""
    for ch in text:
        slot = rack.find(ch)
        if slot < 0:
            out = out + ch
        else:
            out = out + rack[(slot + key) % 26]
    return out

secret = shift("MEET AT NOON", 3)
print(secret)

Predict: The space is not in the rack. Which branch of the gate handles it?

What it actually prints

PHHW DW QRRQ

The first one, because find gives negative one for a space. The space comes through unchanged, which is why word shapes still show in the output. Hiding them is what the pair swap from session 6 does.

Chunk 8 of 8

Decoding is a negative key

To undo a shift of 3, shift by 3 in the other direction. Python's remainder operator handles negative numbers the way a clock does, so the same function decodes with no changes at all.

print((2 - 5) % 26)
print((0 - 1) % 26)

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def shift(text, key):
    out = ""
    for ch in text:
        slot = rack.find(ch)
        if slot < 0:
            out = out + ch
        else:
            out = out + rack[(slot + key) % 26]
    return out

secret = shift("MEET AT NOON", 3)
print(secret)
print(shift(secret, -3))
print(shift(secret, 23))

Predict: Shifting back by 3 and forward by 23 should give the same result. Why?

What it actually prints

23
25
PHHW DW QRRQ
MEET AT NOON
MEET AT NOON

Because 23 and negative 3 land on the same slot once you wrap at 26. Both decode the message. Python computes a remainder that is never negative, which is what makes the negative key work.

Hinge question · reaches back to session 4

Before you build

Question: From session 4: shift returns a string. Write one line that encodes a message twice with a key of 3, and say what single key does the same job.

twice = shift(shift("MEET", 3), 3)
once = shift("MEET", 6)
print(twice)
print(once)

shift(shift("MEET", 3), 3), which is the same as shift("MEET", 6). Shifts add. That is the reason a shift cipher is weak: there are only 25 useful keys, and a program can try all of them in a loop.

Build · 25 minutes

Build: the cipher wheel

  1. Write shift(text, key) from the chunks above, returning rather than printing.
  2. Ask for a message and a key, and print the secret.
  3. Decode it in the same program using a negative key, and confirm you get the message back.
  4. Add a line that prints all 25 possible decodings of a secret you did not choose the key for.
  5. Write down which of the 25 lines is readable, and how you knew.
