Chunk 1 of 7

A string is a row of slots

Text is indexed exactly like a list. Slot 0 is the first character. len counts the characters, spaces included.

word = "SPYGLASS"
print(word[0])
print(word[7])
print(len(word))

Predict: Eight letters. What is in slot 7?

What it actually prints

The last S. Same rule as lists: the last slot is one less than the length.

Chunk 2 of 7

Slicing takes a run of slots

Two numbers in the brackets with a colon between them take everything from the first up to, but not including, the second. Leave a side blank and Python uses the end.

word = "SPYGLASS"
print(word[0:3])
print(word[3:])
print(word[:3])
print(word[2:5])

Predict: word[0:3] gives three letters or four?

Three: slots 0, 1, 2. The same stop-before rule as range. You have now met it three times, which is why it is on the ledger card.

Chunk 3 of 7

Cleaning text you did not type

Input from a person is messy. strip removes spaces from both ends. upper and lower change the case. None of them change the original; each one gives back a new string, which is why the result has to be stored.

raw = "   ada lovelace   "
clean = raw.strip()
print(len(raw), len(clean))
print(clean.upper())
print(raw.upper())
print(len(raw))

Predict: After raw.strip(), how long is raw?

What it actually prints

ADA LOVELACE

18

Still 18. strip handed back a shorter string and left the original alone. Forgetting to store the result is the same mistake as calling int(age) without assigning it, back in session 1.

Chunk 4 of 7

in checks whether one thing is located in another

in is a test, like == or >. It checks whether the thing on its left is located in the thing on its right and gives True or False. Because it gives True or False, it can be a condition in a gate or a while loop, and it can be joined to other tests with and and or.

It works on strings and on lists. With a string it checks for a run of characters. With a list it checks for a whole item. Without it you would have to write a loop to go looking.

word = "SPYGLASS"
print("GLA" in word)
print("Z" in word)
print("S" in word)
riders = ["Ada", "Grace"]
print("Ada" in riders)

Predict: Does in look for a single letter only, or a whole run of letters?

What it actually prints

True
False
True
True

A whole run, in order, with nothing between. GLA is in SPYGLASS; GAL is not. On a list it looks for one whole item, not part of one.

Chunk 5 of 7

replace swaps every copy

replace gives back a new string with every occurrence swapped. Every one, not just the first.

It does not change the string it was called on. message is the same after line 4 as before it. So if you want to keep the changed version, you have to store what replace gives back under a name, the way line 2 does with no_spaces. Line 4 prints the changed version and then throws it away, because nothing stored it. This is the same rule as return in session 5: a value that is handed back has to land somewhere or it is lost.

message = "MEET AT NOON"
no_spaces = message.replace(" ", "*")
print(no_spaces)
print(message.replace("O", "*"))
print(message)

Predict: NOON has two Os. How many get replaced?

What it actually prints

MEET*AT*NOON
MEET AT N**N
MEET AT NOON

Both. And the original is unchanged on the last line, because replace gives back a new string and leaves the old one alone. To keep the starred version you would write message = message.replace("O", "*"), storing the new string under the old name.

Chunk 6 of 7

Building a string one character at a time

Start with an empty string, then add to it inside a loop. This is the accumulator from session 3 with text instead of numbers. Putting the new character in front instead of behind reverses the message.

word = "SPYGLASS"
forward = ""
backward = ""
for ch in word:
    forward = forward + ch
    backward = ch + backward
print(forward)
print(backward)

Predict: Two accumulators, one loop. Which line reverses the word, and why?

What it actually prints

SPYGLASS
SSALGYPS

The one that puts ch first. Each new character shoves the growing string to the right, so the last character read ends up at the front.

Chunk 7 of 7

A loop that waits for a word

Session 2's while loop runs its block again and again while its condition is True. Here the condition compares two strings with !=, which asks whether they are different. The loop keeps asking for a letter and adding it to typed with the accumulator line from chunk 6, and it stops on its own the moment typed matches word.

Look at what the condition does on every pass: it reads the current value of typed, so each new letter changes the answer. The build uses this exact shape, with a function call in place of typed.

word = "SPY"
typed = ""
while typed != word:
    typed = typed + input("Next letter: ")
    print(typed)
print("done")

Predict: The player types S, then P, then Y. How many times does the loop run, and is done printed before or after the third letter?

What it actually prints

Next letter: S
S
Next letter: P
SP
Next letter: Y
SPY
done

Three times, and done comes after. The condition is checked before every pass: after S and after SP it is still True, after SPY the two strings are equal, != gives False, and Python goes to the line after the loop. Type a wrong letter instead and the loop never ends, because typed can never equal word again. That is the bug the build guards against with a second condition joined by and.

Hinge question · reaches back to session 5

Before you build

Question: From session 5: a function that returns. In the build, show(secret, guessed) gives back the word with blanks in it. Explain in one sentence why while show(secret, guessed) != secret: works as a loop condition, and what would go wrong if show ended in print instead of return.

The call turns into the string it returns, so the condition compares that string to the secret, and it is checked again before every pass. With print the call would turn into None, None is never equal to the secret, and the loop would never stop.

Build · 25 minutes

Build: hangman

One player knows a word. The other guesses it one letter at a time. Every letter that is in the word appears in its slot; every letter that is not costs a miss, and six misses ends the game. The word is a string, the guesses are a string that grows, and the row of blanks is built with the accumulator from chunk 6. The program is written below one line at a time. Each line is a question for the room before it goes on the screen. Ask the room first. Open a hint only when the room is stuck, and open the line last.

  1. Write show(secret, guessed) that returns the secret word with a blank for every letter not yet guessed.
  2. Write the game loop: show the word, ask for a letter, and sort the guess into already tried, a hit, or a miss.
  3. After the loop, say whether the player won or ran out of misses.
  4. Add the picture: a list of seven stages, one printed per turn, chosen by the number of misses.
  5. Play it on a word of your own, with at least one wrong guess and one repeated guess.

Tool 3: the picture, one line at a time

A picture made of characters, one stage per miss. The seven stages go in a list, and the number of misses is the index that picks one, because there are seven stages for 0 to 6 misses. One new thing: inside a string, the two characters \n tell print to start a new line, so one string can hold a whole picture.

def show(secret, guessed):
    shown = ""
    for ch in secret:
        if ch in guessed:
            shown = shown + ch
        else:
            shown = shown + "_"
    return shown

secret = "SPYGLASS"
guessed = ""
misses = 0
while misses < 6 and show(secret, guessed) != secret:
    print(show(secret, guessed))
    print(f"misses: {misses} of 6")
    guess = input("Guess a letter: ")
    guess = guess.strip().upper()
    if guess in guessed:
        print("You already tried that one.")
    elif guess in secret:
        guessed = guessed + guess
        print("Yes.")
    else:
        guessed = guessed + guess
        misses = misses + 1
        print("No.")

if show(secret, guessed) == secret:
    print(f"You got it: {secret}")
else:
    print(f"Out of misses. The word was {secret}.")
