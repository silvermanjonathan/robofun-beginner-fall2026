Semester ledger card

Nothing about this course survives at home except this card. One stamp a week, written by hand, in the student's own words. Print it on card stock at the start of term and keep the stack in the room.

How to use it

  • Ten minutes at the end of each session. The student writes, not the teacher.
  • One stamp per session, in the box for that session number.
  • At least one error message per term, copied out by hand.
  • The card comes out again in the retrieval opener the following week.
  • Session 12 reads the card out loud. If a stamp is unreadable, that is the first thing fixed that day.

Reference strip

The syntax that is hardest to remember after a week away. Everything else goes in a stamp, in the student's handwriting.

name = value            a variable: store a value under a name
type(value)             str for text, int for a whole number
int(text)               text to number, on its own line
f"{name} has {n}"       drop values into a sentence
if / elif / else        flat gates, never nested
==  !=  <  >  <=  >=    comparisons, give True or False
and / or                two conditions at once
while condition:        repeats while True; the condition is what stops it
for i in range(5):      0 1 2 3 4, stops before 5
list[0]                 first slot; last is len - 1
text[0:3]               slots 0 1 2, stops before 3
def f(x):               ...    return x * 2
no return               returns None
d = {"key": value}      look up with d["key"]
key in d                True or False, checks keys
a % b                   remainder; wraps a counter
rack.find(ch)           a slot, or -1 for not found
360 / sides             the turn that closes a shape
math.radians(deg)       convert before cos and sin
cos is across, sin down the far end of a step
draw.line(c, col, a, b, 3)  canvas, colour, start, end, width
while running:          pygame frame loop, QUIT sets running = 0
x = x + vx              move once per frame
v = -v                  bounce
level[row][col]         row first, then column

Read the last line of an error first. One change per run.

Error names met this term

Write the real message next to each one, the first time you meet it.

NameWhat it usually meansYour message
NameErrorA word Python does not know. Often a typo.
SyntaxErrorPunctuation. A bracket, a colon, one equals sign where two belong.
IndentationErrorA block is missing, or indented unevenly.
TypeErrorTwo kinds that will not mix. Usually text and number.
IndexErrorA slot past the end. Length and last index are one apart.
